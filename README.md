## Technology

The project uses React and Vite, along with its existing styling and animation dependencies. Three.js is used for 3D effects where configured.

## Run Locally

Install [Node.js](https://nodejs.org/) first.

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Production Build

```bash
npm run build
```

The production output is generated in the `dist` directory.

## Deployment

This project can be deployed with Cloudflare Pages using Git integration.

- Build command: `npm run build`
- Build output directory: `dist`

Commit and push your changes to trigger a new deployment when Git integration is configured.
